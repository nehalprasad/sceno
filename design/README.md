# Design

Phone screens (390×844) for the app, in English (`X.dc.html`) and Hindi (`XHi.dc.html`). `canvas.json` is the canvas layout.

Live canvas: https://claude.ai/artifact/AGDXeG2UREgskWNqVm9LbJ

Each `.dc.html` is a self-contained HTML page in the Design canvas format; open it in the canvas to view it, or read the markup for exact colours, spacing and copy.

Product spec: [`docs/MVP-SPEC.md`](../docs/MVP-SPEC.md).
